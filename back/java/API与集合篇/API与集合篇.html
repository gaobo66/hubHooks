⚠️ 重写equals时必须同时重写hashCode——保证equals相等的两个对象hashCode也相等，否则在HashSet/HashMap中会出现"相同对象无法去重/覆盖"的逻辑错误。

hashCode三规则：

  • 同一对象多次调用hashCode，结果必须一致
  • equals相等的两个对象，hashCode必须相等
  • equals不等的两个对象，hashCode可以相等（哈希冲突，允许）

捕获分组 ​

每组有编号：从1开始，按左括号出现顺序。

java
// 案例1：叠词匹配 "(.)\\1+"  — 捕获任意字符，要求该字符重复至少一次
String pattern1 = "(.)\\1+";      // 匹配：aa, bbb, cccc

// 案例2：词组重复 "(..)\\1+"  — 两个字符为一组
String pattern2 = "(..)\\1+";     // 匹配：abab, abcdabcd

// 案例3：提取日期中的年月日
Pattern p = Pattern.compile("(\\d{4})-(\\d{2})-(\\d{2})");
Matcher m = p.matcher("2026-07-13");
if (m.find()) {
    String year = m.group(1);   // "2026"
    String month = m.group(2);  // "07"
    String day = m.group(3);    // "13"
}

Integer 缓存池原理 ​

Integer.valueOf() 内部维护 [-128, 127] 的 Integer 缓存数组。自动装箱底层也是 valueOf()，所以范围内取缓存对象，范围外 new Integer()。

java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);        // true  — 来自同一缓存对象

Integer c = 128;
Integer d = 128;
System.out.println(c == d);        // false — 超出缓存，是两个不同对象
System.out.println(c.equals(d));   // true  — equals比的是值

六、集合体系总览 ​

Collection (接口) — 单列集合顶层接口
  ├── List (接口)：有序、可重复、有索引
  │     ├── ArrayList：底层 Object[] 数组，查询快 O(1)，增删慢 O(n)
  │     └── LinkedList：底层双向链表，查询慢 O(n)，头尾增删快 O(1)
  └── Set (接口)：无序、不可重复、无索引
        ├── HashSet：底层 HashMap，无序（由哈希值决定）
        │     └── LinkedHashSet：继承HashSet，双向链表+哈希表，保证存取有序
        └── TreeSet：底层 TreeMap，红黑树，可排序

Map (接口) — 双列集合，键值对
  ├── HashMap：数组+链表+红黑树，键无序，允许null键和null值（最常用）
  │     └── LinkedHashMap：继承HashMap，双向链表维护插入顺序
  ├── Hashtable：古老实现，线程安全，不允许null键值（基本不用）
  │     └── Properties：Hashtable子类，专门处理 .properties 配置文件
  └── TreeMap：底层红黑树，键可排序，不允许null键

泛型通配符与PECS原则 ​

通配符说明应用
<?>任意类型，泛型只读只需要读取的场合
<? extends E>E及其子类（上界限定）读取数据——Producer Extends

java
// PECS 原则示例
// extends — 生产者，从中读取
public static double sumOfList(List<? extends Number> list) {
    double sum = 0.0;
    for (Number n : list) { sum += n.doubleValue(); }  // 可以读取为Number
    // list.add(Integer.valueOf(1));  // 编译错误！不能往里添加
    return sum;
}

// super — 消费者，往里写入
public static void addNumbers(List<? super Integer> list) {
    for (int i = 0; i < 5; i++) {
        list.add(i);  // 可以写Integer及子类
    }
    // Integer n = list.get(0);  // 编译错误！读取只能到Object
}

// 实际应用
List<Integer> ints = Arrays.asList(1, 2, 3);
double sum = sumOfList(ints);  // List<Integer> 是 List<? extends Number>

List<Number> numbers = new ArrayList<>();
addNumbers(numbers);  // List<Number> 是 List<? super Integer>

HashSet底层——哈希表 ​

  • JDK8前：数组 + 链表（头插法，多线程扩容时可能成环→死锁）
  • JDK8起：数组 + 链表 + 红黑树（尾插法解决死锁问题）
    • 链表长度 > 8 且数组长度 >= 64 → 树化（将查询从 O(n) 降到 O(log n)）
    • 红黑树节点数 <= 6 → 退化回链表
  • 加载因子 0.75：元素数 / 数组容量 >= 0.75 时触发扩容，扩容为原来的2倍

class Student implements Comparable<Student> {
    @Override
    public int compareTo(Student o) {
        // 返回：负数(<)、0(=，不会存入!)、正数(>)

    }
}

    int result = o1.getAge() - o2.getAge();
    return result == 0 ? o1.getName().compareTo(o2.getName()) : result;
});

HashMap 底层原理 ​

  1. 默认加载因子 0.75，首次 put 时数组初始化容量为默认值 16
  2. put(K, V) 流程：
    • 计算key的hash → (capacity - 1) & hash 得到桶索引
    • 桶为空 → 直接放入
    • 桶不为空 → equals 逐一比较链表/红黑树节点
      • 有相等的key → 覆盖旧value
      • 都不同 → 尾插法挂在链表末尾，或插入红黑树
  3. 链表 > 8 且数组容量 >= 64 → 链表转红黑树
  4. 扩容：元素数 > 容量 × 加载因子 时扩容为2倍，所有元素 rehash 重新分布
  5. 树转为链表条件：扩容(resize)时节点数 <= 6

// (n - 1) & hash   → n是数组长度，必须是2的幂次才能保证均匀分布
// 为什么容量是2的幂？→ 为了让 hash % n 等价于 hash & (n-1)，用位运算取模

十三、Stream流 ​

设计思想 ​

流水线式处理集合/数组，特点：

  • 不存储数据：只是对数据源的视图操作
  • 不修改数据源：每次操作产生新Stream
  • 惰性求值：终结操作才触发整个流水线执行
  • 一次性：一个Stream只能消费一次，用完即关闭

获取Stream ​

java
// 单列集合
Stream<String> s1 = list.stream();                   // 串行流
Stream<String> s1p = list.parallelStream();          // 并行流

// 双列集合
Stream<String> ks = map.keySet().stream();
Stream<Integer> vs = map.values().stream();
Stream<Map.Entry<String, Integer>> es = map.entrySet().stream();

// 数组
Stream<Integer> s2 = Arrays.stream(arr);             // int数组
Stream<String> s3 = Stream.of("a", "b", "c");        // 可变参数

// 无限流
Stream<Integer> infinite = Stream.iterate(0, n -> n + 1);  // 0,1,2,3...
Stream<Double> randoms = Stream.generate(Math::random);    // 随机数流

中间操作（返回Stream，可链式调用） ​

方法说明
filter(Predicate)过滤满足条件的元素
limit(long n)取前n个
skip(long n)跳过前n个
distinct()去重（依赖 hashCode/equals）
map(Function)将每个元素转换为另一种类型
flatMap(Function)每个元素转Stream后再合并为一个Stream（扁平化）
sorted()自然排序
sorted(Comparator)自定义排序
peek(Consumer)调试用，中间查看每个元素（不影响数据）
takeWhile(Predicate)JDK9+：从头开始取满足条件的，一旦不满足就停
dropWhile(Predicate)JDK9+：从头开始去掉满足条件的

终结操作（触发执行，不可再链式） ​

方法返回说明
forEach(Consumer)void遍历每个元素
forEachOrdered(Consumer)void按顺序遍历（并行流保持顺序）
count()long元素数量
collect(Collector)R收集到集合或其他容器
toArray()Object[]收集到数组
reduce(init, BinaryOp)Optional/T归约/聚合
anyMatch(Predicate)boolean至少一个满足？
allMatch(Predicate)boolean全部满足？
noneMatch(Predicate)boolean全不满足？
findFirst()Optional第一个元素
findAny()Optional任意一个元素（并行流更快）
max(Comparator)Optional最大值
min(Comparator)Optional最小值

核心操作示例 ​

java
// ===== filter + map + collect =====
List<String> longNames = students.stream()
    .filter(s -> s.getAge() > 18)
    .map(Student::getName)
    .filter(name -> name.length() > 2)
    .collect(Collectors.toList());

// ===== flatMap — 扁平化（每个元素转Stream后合并）=====
// 需求：多个列表中取出所有单词，去重
List<List<String>> sentences = Arrays.asList(
    Arrays.asList("hello", "world"),
    Arrays.asList("java", "world", "python")
);
List<String> words = sentences.stream()
    .flatMap(List::stream)       // 将每个List转Stream，再合并
    .distinct()
    .collect(Collectors.toList());
// → ["hello", "world", "java", "python"]

// ===== reduce — 归约/聚合 =====
// 求和
Optional<Integer> sum = Stream.of(1, 2, 3, 4, 5)
    .reduce((a, b) -> a + b);      // 无初始值 → Optional，空流时empty

Integer sum2 = Stream.of(1, 2, 3, 4, 5)
    .reduce(0, (a, b) -> a + b);   // 有初始值 → 返回具体类型，空流时返回初始值

// 求最大值
Optional<Integer> max = Stream.of(1, 5, 3, 9, 2).reduce(Integer::max);

// ===== sorted =====
List<Student> sorted = students.stream()
    .sorted((s1, s2) -> s2.getAge() - s1.getAge())  // 年龄降序
    .collect(Collectors.toList());

Collectors 收集器方法 ​

java
// 收集到集合
Collectors.toList()                          // → List（默认ArrayList）
Collectors.toSet()                           // → Set（默认HashSet）
Collectors.toCollection(LinkedList::new)     // → 指定集合类型

// 收集到Map（key不能重复，否则抛异常）
Map<String, Integer> map = students.stream()
    .collect(Collectors.toMap(Student::getName, Student::getAge));
// 处理key重复（保留后者）
Map<String, Integer> map2 = students.stream()
    .collect(Collectors.toMap(
        Student::getName, Student::getAge,
        (oldVal, newVal) -> newVal));  // key冲突时取新值

// 分组 — groupingBy
Map<String, List<Student>> byCity = students.stream()
    .collect(Collectors.groupingBy(Student::getCity));  // 按城市分组
// 分组+统计
Map<String, Long> countByCity = students.stream()
    .collect(Collectors.groupingBy(Student::getCity, Collectors.counting()));
// 分组+每组年龄平均值
Map<String, Double> avgAgeByCity = students.stream()
    .collect(Collectors.groupingBy(Student::getCity,
        Collectors.averagingInt(Student::getAge)));

// 分区 — partitioningBy（key为true/false）
Map<Boolean, List<Student>> adultPartition = students.stream()
    .collect(Collectors.partitioningBy(s -> s.getAge() >= 18));

// 统计 — summarizing
IntSummaryStatistics stats = students.stream()
    .collect(Collectors.summarizingInt(Student::getAge));
stats.getMax();    // 最大年龄
stats.getMin();    // 最小年龄
stats.getAverage();// 平均年龄
stats.getCount();  // 人数

// 字符串拼接
String names = students.stream()
    .map(Student::getName)
    .collect(Collectors.joining(", ", "[", "]"));  // [张三, 李四, 王五]

十四、方法引用 ​

简化Lambda的写法。前提：重写方法的参数列表和返回值类型与Lambda一致。

格式等效Lambda条件示例
类名::静态方法(a,b,...) → 类.静态方法(a,b,...)全部参数原样传入静态方法Integer::parseInt
对象::实例方法(a,b,...) → 对象.实例方法(a,b,...)全部参数原样传入实例方法System.out::println
类名::实例方法(a,b,...) → a.实例方法(b,...)第一个参数是调用者String::length
类名::new(a,b,...) → new 类(a,b,...)构造方法引用Student::new
数组::newn → new 类型[n]数组构造int[]::new
java
// 实际应用场景
// 1. 遍历打印
list.forEach(System.out::println);

// 2. 字符串→整数
Stream.of("1","2","3").map(Integer::parseInt).collect(Collectors.toList());

// 3. 获取学生姓名
students.stream().map(Student::getName).collect(Collectors.toList());

// 4. 构造对象
List<Student> students = names.stream().map(Student::new).collect(Collectors.toList());

// 5. 创建数组
Stream<String> stream = Stream.of("a", "b", "c");
String[] array = stream.toArray(String[]::new);  // 替代 toArray(new String[0])
