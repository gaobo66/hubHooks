中间件 (Middleware) ​

全局（.middleware 前缀）或命名中间件（middleware/ 目录），在路由切换前执行：

ts
// middleware/auth.ts
export default defineNuxtRouteMiddleware((to, from) => {
  const token = useCookie('token')
  if (!token.value) {
    return navigateTo('/login')
  }
})

插件 (Plugins) ​

plugins/ 目录，用于注册全局功能（第三方库、自定义指令、provide/inject 等）：

ts
// plugins/vuetify.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.use(Vuetify)
  // 注入全局方法
  return {
    provide: {
      hello: () => 'world'
    }
  }
})

Layers（层） ​

Layers 允许将项目拆分为可复用的层级（类似 NPM 包但零配置共享）：

ts
// nuxt.config.ts
export default defineNuxtConfig({
  extends: [
    'github:org/repo',          // Git 仓库
    '../local-theme',           // 本地目录
    '@my-org/nuxt-layer'       // npm 包
  ]
})

页面过渡 ​

export default defineNuxtConfig({

    layoutTransition: { name: 'layout', mode: 'out-in' }

useState（内置轻量方案） ​

Nuxt 原生响应式状态，可在服务端预填充、客户端接管：

ts
// composables/useCounter.ts
export const useCounter = () => useState('counter', () => 0)

常用 Composables ​

useCookie ​

SSR 安全的 Cookie 操作，服务端可读写：

ts
const token = useCookie('token')
const userInfo = useCookie('userInfo', {
  maxAge: 60 * 60 * 24 * 30,
  secure: true,
  sameSite: 'lax'
})

// 读：token.value
// 写：token.value = 'new_value'
// 删：token.value = null

自定义指令 ​

通过插件注册全局指令：

ts
// plugins/directives.ts
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.vueApp.directive('focus', {
    mounted(el) { el.focus() }
  })
  nuxtApp.vueApp.directive('color', {
    mounted(el, binding) { el.style.color = binding.value }
  })
})
